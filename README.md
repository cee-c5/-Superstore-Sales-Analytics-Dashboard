📊 Superstore Sales Analytics Dashboard

An interactive Power BI dashboard analyzing Superstore sales performance from 2014–2017, built to surface revenue, profit, and operational insights for data-driven decision-making.

🎯 Project Overview

This project transforms raw retail sales data into an executive-ready dashboard, tracking key performance indicators against annual goals and breaking down performance by geography, segment, category, and sales team.

🔑 Key Metrics Tracked

Metric	Value	vs. Goal
Revenue	$3.58M	+17.53%
Profit	$93.44K	+14.24%
Profit Margin	0.03	-2.8%
Total Orders	3,312	—
Total Cost	$3.49M	+17.62%

📈 Dashboard Features

	•	Sales Trend Analysis — Year-over-year revenue trajectory (2014–2017)
	•	Geographic Breakdown — Revenue by city (NYC, LA, Seattle lead)
	•	Segment Analysis — Consumer vs. Corporate vs. Home Office (donut chart)
	•	Shipping Mode Insights — Standard vs. Second/First Class vs. Same Day
	•	Category/Sub-Category Treemap — Technology, Furniture, Office Supplies breakdown
	•	Running Totals — 30-day and 90-day rolling revenue trends
	•	Sales Team Performance Table — Rep-level revenue and profit tracking
	•	Dynamic Filters — Year, Region, and Category slicers for interactive exploration

🛠️ Tools Used

	•	Power BI — Data modeling, DAX measures, visualization
	•	DAX — Custom measures for goal tracking, running totals, and YoY comparisons
	•	TMDL — Model scripting
